📘 Câu hỏi 08 - Lý thuyết JavaScript

1. JavaScript là gì? Dùng để làm gì trong thiết kế web?

JavaScript là ngôn ngữ lập trình chạy trên trình duyệt. Nó làm cho trang web tương tác được: xử lý sự kiện (bấm nút, nhấn phím), thay đổi nội dung trang, kiểm tra form, lấy dữ liệu từ máy chủ, làm hiệu ứng và game.

2. Các kiểu dữ liệu chính trong JavaScript?

Kiểu nguyên thủy: string, number, bigint, boolean, undefined, null, symbol. Kiểu tham chiếu: object (gồm mảng, hàm...).

3. Khác nhau giữa var, let và const?

var có phạm vi theo hàm và cho khai báo lại. let và const có phạm vi theo khối { } và không được khai báo lại. let gán lại được, const thì không (bắt buộc gán giá trị ngay khi khai báo).

4. JavaScript có phải ngôn ngữ đơn luồng không?

Có. JavaScript chỉ chạy một việc tại một thời điểm trên một luồng. Các việc chờ như setTimeout hay fetch được xử lý bất đồng bộ qua Event Loop nên trang không bị treo.

5. Hàm delete có tác dụng gì?

delete (thực chất là toán tử) dùng để xóa một thuộc tính khỏi đối tượng, ví dụ delete user.age. Nó không xóa được biến khai báo bằng var, let, const.
